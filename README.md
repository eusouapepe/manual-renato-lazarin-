# Renato Lazarin - Manual de Marca - 150 páginas

Manual oficial em formato revista de luxo Assouline.

## Publicar no GitHub Pages (1 minuto)
1. Crie um repositório novo no GitHub (pode ser privado)
2. Faça upload de todos os arquivos deste ZIP para a branch main
3. Vá em Settings > Pages > Source: GitHub Actions
4. Dê push - o link sai em Actions > Deploy

Link final: https://SEU_USUARIO.github.io/NOME_DO_REPO/

Navegação: setas, clique nas laterais ou no contador 1/150.
